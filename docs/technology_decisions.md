# Technology Decisions

## Python

Python is used as the primary language because AIDesk combines:

- AI
- Machine Learning
- LLMs
- RAG
- Data processing
- APIs

## FastAPI

FastAPI will provide the production backend API.

## Streamlit

Streamlit will provide the initial analytics and AI interface.

## PostgreSQL

PostgreSQL will store structured business data.

## pgvector

pgvector will provide vector similarity search inside PostgreSQL.

## LangGraph

LangGraph will be used to orchestrate agentic workflows.

## Docker

Docker will provide reproducible application environments.

## GitHub Actions

GitHub Actions will be used for CI/CD.

## Prometheus + Grafana

Prometheus and Grafana will provide application monitoring and visualization.

## MLflow

MLflow will be used for experiment tracking.

## LangSmith

LangSmith will be used for LLM/agent tracing and observability.
